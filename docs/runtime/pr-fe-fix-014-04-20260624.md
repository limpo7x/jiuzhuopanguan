  - `ManagedLiveSession`、`ManagedSessionMomentSummary` 增加 `firstPhotoUploadedAt/hasFirstPhoto/isActiveForResume`。

- `miniprogram/utils/first-photo-state.ts`
  - 新增统一首拍状态判断：`hasFirstPhotoEvidence()`、`isActiveForResumeByFirstPhoto()`、`isEndedFirstPhotoState()`。
- `miniprogram/pages/album/index.ts`
  - `ongoingCount`、进行中列表、筛选结果共用 `hasFirstPhoto/isActiveForResume` 分类。
  - 待首拍聚会不进入相册进行中分组。
- `miniprogram/pages/ledger/index.ts|wxml|less`
  - 账本新增 `sessionViewState`，区分无聚会、待首拍、进行中、已结束。
  - 待首拍时不显示“回到本局”，发起人进入首拍，成员看到等待提示；保留创建聚会入口。
  - 首拍前不允许编辑账本。
- `miniprogram/pages/waiting-room/index.ts|wxml|less`

  - 发起人首拍前主按钮为“去拍第一张照片”；成员为“等待首张照片”。
  - 首拍后才自动/手动进入记录页。
- `miniprogram/pages/index/index.ts`、`miniprogram/pages/me/index.ts`
  - 首页继续记录条与我的进行中统计优先消费 `isActiveForResume`，保留封面图 fallback 兼容旧数据。
