# PR-BE FIX-014-03 首拍进行中状态后端合同

## 范围

- 任务：`FIX-014-03`，把“首张有效照片保存后才算进行中/可继续记录”的状态沉到后端合同。
- 技术边界：仅 `api.pomer.cn` / `jiuzhuopanguan`；未触碰 `pomer.cn` 公司官网。
- 本轮只做本地后端/API 合同与 smoke；未提交、未推送、未部署、未上传小程序包。

## 改动

- `backend/data/admin.js`
  - 新增 session 首拍状态归一化：`firstPhotoUploadedAt`、`hasFirstPhoto`、`isActiveForResume`。
  - 新建聚会默认 `hasFirstPhoto=false`、`isActiveForResume=false`。
  - 新增 `markManagedSessionFirstPhotoUploaded()`，首张有效图片保存后写回 session，且不覆盖首次时间。
  - 后台 `sessions` 页面和统计改用同一首拍合同，增加“首拍状态/首拍时间”字段。
- `backend/data/moments.js`
  - `createMoment()` 保存带 `imageUrl` 的完整 moment 后写回 session 首拍状态。
  - `/user/session-moment-summaries` 返回 `firstPhotoUploadedAt/hasFirstPhoto/isActiveForResume`，封面仍取本局第一张上传图。
  - 公开分享摘要补同样首拍字段。
- `backend/data/front.js`
  - `/sessions/live` app_store facade 返回同一首拍字段。
- `backend/data/normalized-read.js`
  - normalized 读路径不做 DDL，改为从 `moment_records` 第一张有效图片推导同一首拍字段，覆盖 `/sessions/live` 和 `/user/session-moment-summaries`。
- `backend/server.js`
  - 匿名 invite 公开视图也返回无敏感的首拍状态字段。
- `backend/scripts/smoke-first-photo-active-state.js`
  - 新增本地 smoke，覆盖创建未首拍、首拍后、结束后三个状态。
- `backend/scripts/smoke-live-session-privacy.js`
  - 更新公开字段白名单，确认新增首拍状态不属于私有泄露。
