## FE-R01 退回复核

时间：2026-06-24

### 退回原因

QA 使用真实非成员 tokenTail `b81a4c83` 直达 `/pages/share-poster/index?sessionId=session-1782137141037-b4e84c` 时，页面仍停在 `shareViewState=ready`、`canViewPosterContent=true`、`shareActionBlocked=false`，虽然照片和时间线为空，但生成/刷新入口仍可见。

前端复核确认：真实接口错误会先进入 `errorText` 的安全中文文案，例如“当前账号暂不能查看这张分享页，请使用邀请入口进入本场聚会”。旧映射只识别英文合同错误或部分中文文案，且 fallback 摘要加载后可能保持 ready 状态。

### R01 改动

- `miniprogram/pages/share-poster/index.ts`
  - 新增 `getShareErrorText()`，保留 `Error.message`、对象 `message`、`data.message`、`errMsg`，避免对象错误被转成 `[object Object]`。
  - `getShareAuthErrorKind()` 补充中文权限文案映射：`当前账号暂不能查看`、`暂不能查看这张分享页`、`没有这场聚会的分享权限`、`没有分享权限` -> `noPermission`。
  - 新增 `shouldBlockShareViewForError()`，先判断原始错误，再判断 `toSafeShareErrorText()` 后的安全文案。
  - 新增 `applyBlockedErrorTextState()`，任何加载分支写入阻断类 `errorText` 后立即调用 `applyPosterUnavailableState()`，清空照片、时间线、总结、二维码和 ready 分享图，并停止后续 fallback。
  - `loadBriefByQuery()` 各 catch fallback 前补阻断 return，避免 `loadLiveSessionSummary()` 或 runtime fallback 把页面维持在 ready。
