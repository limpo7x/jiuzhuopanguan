## 已实现

- `miniprogram/pages/share-poster/index.ts`
  - 新增 `from/returnMode/returnFilter` 解析，保存为 `shareReturnSource/shareReturnMode/shareReturnFilter`。
  - 顶部返回 `handleBackTap()` 先检查页面栈，`getCurrentPages().length > 1` 时优先 `wx.navigateBack({ delta: 1 })`。
  - 无页面栈或 `navigateBack` 失败时，按来源 fallback：
    - `from=finish` -> `/pages/album/index?mode=shares`
    - `from=wine-history` -> `/pages/wine-history/index?mode=<returnMode>&filter=<returnFilter>`
    - `from=album` -> `/pages/album/index?mode=<returnMode>&filter=<returnFilter>`
    - `from=me` -> `/pages/me/index`
    - `from=result-report` -> `/pages/result-report/index?reportId=<reportId>`
    - `from=session-brief` -> `/pages/session-brief/index?briefId=<briefId>&sessionId=<sessionId>`
    - `from=external` 或无来源 -> `/pages/index/index`
  - `onShareAppMessage()` 和 `onShareTimeline()` 统一给外部分发路径追加 `from=external`，避免外部接收者继承内部来源。
- `miniprogram/pages/share-poster/index.wxml`
  - 底部独立命令从“退出分享”改为“返回首页”，继续绑定 `handleExitShareTap()`，与顶部返回分离。
- `miniprogram/pages/live-record/index.ts`
  - 结束聚会后进入分享页追加 `from=finish`。
- `miniprogram/pages/wine-history/index.ts`
  - 已结束记录进入分享页追加 `from=wine-history&returnMode=<mode>&returnFilter=<activeFilter>`。
  - 页面支持 `filter` 查询恢复筛选 chip，返回后不丢当前筛选状态。
- `miniprogram/pages/result-report/index.ts`
  - 报告页进入分享页追加 `from=result-report`。
