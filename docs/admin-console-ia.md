# 酒桌判官后台管理程序功能列表与页面架构

## 1. 目标与判断

后台不是简单的“改 Banner 工具”，而是服务这三个经营目标：

1. 维持酒局主流程可运营：模板、题库、酒局、战报、分享链路要可配、可查、可控。
2. 支撑商业化闭环：积分、会员、广告、商户券、分享裂变都要进入统一运营后台。
3. 支撑增长与风控：用户、酒友关系、拍一拍、活动转化、内容合规、管理权限都要能被管理。

结合当前仓库现状：

- 已有最小后台：首页 Banner、积分商城、模板包。
- 已有真实业务数据入口：用户资料、酒友搜索/增删改、拍一拍线程、二维码生成、工具历史。
- 已有明确商业化方向：积分任务、积分商品、模板解锁、会员权益、商户优惠、广告特权、分享裂变。

因此，目标后台应是“内容运营 + 商业化运营 + 用户增长 + 系统配置”一体化控制台。

## 2. 功能范围分层

### 2.1 P0：必须首批具备

- 登录与权限控制
- 首页装修与推荐位管理
- 酒局模板与题库管理
- 积分任务、积分商品、模板解锁策略管理
- 商户与优惠券管理
- 广告位与激励视频策略管理
- 分享海报、邀局卡片、分享码配置
- 用户、酒局、战报基础查询
- 数据概览与关键转化看板
- 系统配置、操作日志、合规配置

### 2.2 P1：跟随增长补齐

- 会员套餐与权益编排
- 活动运营与专题落地页
- 用户标签、分群、定向投放
- A/B 实验与版本灰度
- 内容审核、举报处理、敏感词策略

### 2.3 P2：规模化后再做

- 财务结算与分账
- 商户 CRM 与线下核销对账
- 自动化营销任务
- BI 自定义报表

## 3. 角色与权限

### 3.1 超级管理员

- 拥有所有模块权限
- 管理账号、角色、系统配置、发布策略

### 3.2 内容运营

- 管理首页、模板、题库、分享素材、活动专题

### 3.3 商业化运营

- 管理积分、会员、广告、商户券、转化活动

### 3.4 用户运营

- 管理用户资料、酒局记录、战报、酒友关系、拍一拍线程

### 3.5 数据分析

- 只读访问经营看板、增长分析、转化漏斗、活动效果

## 8. 后台界面设计原则

### 8.1 视觉基调

- 延续小程序现有品牌语义：暖白、奶油橙、深棕、金色点缀。
- 避免通用企业蓝后台，保持“聚会产品”识别度。
- 大面积留白 + 圆角卡片 + 轻边框，沿用前台的轻量氛围。
- 重点操作使用橙红主按钮，会员/高价值区域可用深色底 + 金色标签。

### 8.2 交互基调

- 一级导航清晰，不堆一屏入口。
- 二级列表页强调筛选、状态、批量操作。
- 三级编辑页必须实时预览，减少运营反复发布试错。
- 商业化相关页面要把“收益 / 转化 / 生效范围”放在首屏。

### 8.3 组件规范

- 颜色建议：`#FFFDF8`、`#FFF8EE`、`#24160F`、`#FF5B3D`、`#FF7645`、`#F4D4AD`
- 圆角建议：12/16/20
- 主要容器以浅边框分层，不依赖重阴影
- 列表页默认表格 + 右侧详情抽屉
- 编辑页默认左右分栏：表单 7 栅格，预览 5 栅格

## 9. 当前后台与目标后台差距

当前已具备：

- 首页 Banner 配置
- 积分商城配置
- 模板包配置

当前明显缺失：

- 登录鉴权与权限系统
- 酒局模板完整管理
- 题库与任务管理
- 商户、优惠券、会员、广告、分享素材管理
- 用户、酒局、战报查询
- 经营数据与增长分析
- 审核、日志、灰度发布

## 10. 建议的实施顺序

1. 先补后台登录、角色权限、操作日志。
2. 扩展内容运营：首页装修、模板、题库、分享素材。
3. 扩展商业化：积分、广告、商户券、会员。
4. 扩展用户与酒局查询：用户、酒友、酒局、战报。
5. 最后补增长分析、内容审核、活动运营。

这样能保证后台先支撑上线运营，再逐步补深度能力。
