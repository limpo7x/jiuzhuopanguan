## 3. 视觉系统锁定

- 产品名：新增可见文案统一为“聚会记录师”。
- 主语义：聚会、记录、相册、分享、回忆、好友。
- 降权语义：玩法、榜单、积分、工具、会员和历史兼容入口均不阻断默认创建与拍照路径。
- 禁用默认旧词：新增 UI 不使用“酒桌判官、判官、欠酒、惩罚、裁判、酒局玩法”作为主标题、主按钮或默认流程。
- 主色：珊瑚橙用于主 CTA；蓝色用于次 CTA、分段控件和导航；薄荷绿用于成功、隐私、安全提示。
- 背景：白底或浅暖灰底，允许低饱和贴纸和轻插画，不使用厚重渐变背景。
- CTA：高度 52px，圆角 14px，左右安全内边距 24px；375/390/414 宽度下不得溢出。
- 卡片：避免卡片套卡片；列表项优先轻量行、缩略图条、双列相册或分组折叠。
- 长列表：超过 5 项必须使用“精选 3 项 + 更多”、分组折叠、横滑、搜索或二级页。
- 图片：头像、照片和二维码区域必须有固定比例和安全区，不得 `aspectFill` 裁掉关键文字或主体。

## 6. 前端实践清单

1. 页面骨架：每页采用 `page` 基础面 + 顶部标题 + 内容分组 + 底部安全区，不使用大卡片包整页。
2. 底部 CTA：固定底部按钮必须预留安全区；双按钮用等宽 grid，最长中文文案不换行。
3. 缩略图：相册缩略图统一 4:3 或 1:1，列表中最多露 3 张，更多用数字或入口表达。
4. 分段控件：用于相册、分享图、榜单分类；分段项不超过 3 个，超过 3 个改横滑或二级页。
5. 状态表达：loading、empty、error、disabled、retry 都要有短文案和下一步，不使用只有 spinner 的空白状态。
6. 登录降级：`wine-history` 未登录或 token 失效时展示登录引导，不持续请求鉴权接口。
7. 分享过滤：分享预览必须明确仅包含授权和审核通过照片；私密、待补图、隐藏、未授权内容不得进入公开预览。
8. 榜单降权：`rankings` 不作为创建/拍照默认路径；入口来自相册、简报或历史，不在首页主 CTA 抢位。
9. 贴纸使用：贴纸只做引导和空态，不能遮挡二维码、房间码、按钮、照片主体和状态提示。
10. 旧入口兼容：历史“酒桌判官”能力可在历史兼容或高级设置中保留，但主路径文案和视觉必须使用“聚会记录师”。
